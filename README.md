# Tutorial 1 — Products API

University of Westminster Object Oriented Programming lab project, built with Java and Spring Boot.

## Features

- `/hello` — returns a greeting.
- `/goodbye` — returns a goodbye message.
- `/status` — returns the API status and current date.
- `Person` class with name and email fields.
- Swagger UI for viewing and testing the endpoints.

## Running the application

Open the project in IntelliJ IDEA and run `ProductsApiApplication`.

The application runs at http://localhost:8080.

Swagger UI: http://localhost:8080/swagger-ui/index.html
